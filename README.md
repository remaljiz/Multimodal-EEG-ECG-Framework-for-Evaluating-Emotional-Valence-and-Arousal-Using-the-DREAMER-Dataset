# Multimodal-EEG-ECG-Framework-for-Evaluating-Emotional-Valence-and-Arousal-Using-the-DREAMER-Dataset
This project builds a multimodal EEG–ECG framework using the DREAMER dataset to evaluate emotion through valence and arousal. EEG frontal alpha asymmetry estimates positive or negative affect, while ECG HRV features assess autonomic arousal, comparing calm and fear conditions.
